DIMENSION 1

Vendor Type

"What are you?" — Each vendor has exactly ONE. Drives the Vendor Explore page browsing.

DIMENSION 2

Service Type

"What do you offer?" — Multiple per vendor, but must belong to their Vendor Type. Drives Service Explore page.

DIMENSION 3

Event Types Served

"Who do you serve?" — Multiple per vendor. Powers the recommendation engine matching score.
