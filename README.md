Graduation Project

This repository contains the source code and documentation for our graduation project.
The project is structured into three main folders and organized with three Git branches for better development workflow.

📂 Project Structure

API/
Contains the backend code (ASP.NET Core Web API).
Responsible for authentication, database operations, and serving data to the frontend.

Frontend/
Contains the client-side application (e.g., React, Angular, or plain HTML/CSS/JS).
Handles the user interface and communicates with the API.

Docs/
Contains documentation, reports, ER diagrams, and other resources related to the project.
